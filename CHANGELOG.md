## Template Guidelines

**Format for each entry:**
```
- `[Member Name]` - [Action]: [Specific description with context]
```

**Example entries:**
- `[John Doe]` - Added: Created Azure Resource Group 'rg-azure-project' in Southeast Asia region
- `[Jane Smith]` - Changed: Updated NSG rules to restrict SSH access to admin IPs only (203.0.113.0/24)
- `[Jane Smith]` - Fixed: Corrected Bicep parameter syntax error in storage account naming
- `[John Doe]` - Removed: Deleted unused test VM to reduce monthly costs by $50

**Requirements:**
- ✅ Every team member must contribute entries
- ✅ All entries must include dates (YYYY-MM-DD)
- ✅ Descriptions must be specific and actionable
- ✅ Minimum 5 entries per member throughout project
- ✅ Update regularly throughout development
- ✅ Cover all deliverables: architecture, IaC, cost report, presentation
